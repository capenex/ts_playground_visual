双引擎类型检查说明（内置高速 AST 引擎 + 后台 Web Worker 官方 tsc）

      
本项目同时运行内置子集检查器（毫秒级实时响应）与后台 Web Worker 官方 TypeScript 编译器，两者均实时读取上方的 tsconfig.json 配置。

      
    
        
  • 基础类型注解、数组/联合类型、interface / type 对象结构、泛型与条件类型
    • 
        
  • 函数参数、返回类型、常用数组 / Map / Set / Math 方法和跨文件 ES Module 导入导出检查
    • 
        
  • 开启「新手宽松模式」时，即使写了未标注类型的 JS 风格代码也能顺畅单步可视化推导
    • 
      

      
提示：你也可以展开右侧「📁 文件目录」，直接点击打开 tsconfig.json 手动修改 JSON 配置。
