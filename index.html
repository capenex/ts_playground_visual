      内置检查器 · 范围与限制
      
    

    

      
这不是完整的 TypeScript 编译器（tsc）。它是项目内置的子集检查器，不调用官方语言服务，也不做跨文件或完整的类型推断。

      
TypeScript 模式覆盖

      
    
        
  • 基础类型注解、数组/联合类型、interface / type 对象结构
    • 
        
  • 函数参数、返回类型、常用数组 / Map / Set / Math 方法和简单表达式
    • 
        
  • 对象属性链、模板字符串插值、基础赋值 / 比较 / 调用检查
    • 
        
  • 内置样例和常见算法代码里的类型错误
    • 
      

      
TypeScript 模式不覆盖

      
    
        
  • 完整泛型推断与约束、条件类型、映射类型、交叉类型
    • 
        
  • 复杂类型收窄、声明合并、命名空间 / 模块解析、跨文件类型
    • 
        
  • 装饰器、JSX / TSX、完整标准库类型、类型级运算、satisfies 的完整语义
    • 
        
  • 所有 tsc 的诊断规则与错误码
    • 
      

      
Python 模式

      
只做运行前语法检查（ast.parse / compile），不做静态类型检查；类型注解不参与校验。

      
因此可能出现漏报（错误没标红）或误报（合法写法被标红）。以实际运行结果和官方 tsc 为准。
