## 主要失败原因

1. **非空断言未剥离（6 题）**：`node.next!` 等语法导致 `Unexpected token '!'`。链表基础 5 题里 4 题因此失败，合并 K 个链表也失败。
2. **`new Array<T>(n).fill(...)` 检查器误判（12 题）**：把 `.fill(false/0)` 的返回类型推断成元素类型，产生 `TS2322 boolean → number[]`。大量 DP/回溯题受影响。
3. **可空/联合类型推断误报（6 题）**：树构造函数的 `(number|null)[]`、`ListNode|null`、`GraphNode|null` 被误判；导致二叉树遍历整组 5 题全失败、克隆图失败。
4. **其他类型检查边界（5 题）**：`while(true)` 内返回被报缺少 return；部分递归/返回路径推断错误。
5. **循环结构序列化崩溃（1 题）**：复制随机指针链表在完成时触发 circular structure JSON 序列化异常。
6. **Debug 步数上限（1 题）**：单词接龙达到 2000 步熔断，未能完成回放。

## 建议优先级

1. `stripTypes` 支持 TS 非空断言 `expr!`（删掉 `!` 并保持行号）。
2. 修正 `new Array<T>(len).fill(value)` 的返回类型推断。
3. 改进可空/联合类型与 `while(true)` 的返回路径判断。
4. 结果日志/返回值的循环结构安全序列化。
5. 评估 2000 步上限是否对算法题调试足够，或提供可配置上限。
